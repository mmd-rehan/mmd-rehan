Questions clients ask

Before we start

What kind of projects do you take on?
I build web applications, websites and custom software systems. That includes dashboards, booking and admin portals, APIs and integrations, mobile apps, and upgrades to existing systems that have become slow or hard to change.
Where are you based and who have you worked with?
I am Muhammad Rehan, a full-stack developer based in Dubai, UAE. I have built software for airlines, healthcare providers, a bitcoin mining operator, restaurants and a global logistics company.
Which technologies do you use?
I work with Angular, React and TypeScript on the front end, Node.js and Spring Boot on the back end, Flutter and React Native for mobile, SQL and MongoDB for data, and Docker, AWS and Azure DevOps for deployment.
Can you fix or upgrade an existing system?
Yes. I have led a monolith to microservices migration, run a live database migration using a parallel stack, and brought update downtime close to zero for a mining platform with 300,000+ machines.
How do I start a project with you?
Email hi@mmd-rehan.com with a few lines about what you want to build or fix. A short message is enough, and I will take it from there.
