How a project runs

From first call to go-live

You work with me directly the whole way, from the first call to the deploy.

  1. TalkA short call about the problem, who will use the app and what already exists.
  2. ScopeA written plan with the first version, the screens, the integrations and what comes later.
  3. PrototypeClickable screens early, so you see the app before the heavy building starts.
  4. BuildSmall releases you can open and try, instead of one big reveal at the end.
  5. LaunchDeployment, monitoring and handover notes, so the app keeps running after go-live.
Technology

The stack, and why

I pick tools for how long your app needs to live and who will maintain it, not for what is trending.

Front end
Angular and NgRx for large apps with many screens and forms. React when speed and a lighter setup matter more. Always TypeScript.
Back end
Node.js with Express or NestJS for APIs. Spring Boot or .NET when the project already lives there.
Data
PostgreSQL, SQL Server or MySQL for business data. MongoDB, including geospatial queries, when the shape fits.
Delivery
Docker, CI/CD on Azure DevOps or GitHub, AWS and Nginx. Releases are repeatable and boring, which is the goal.
Questions

Web app development questions

Do you build web apps for businesses in Dubai?
Yes. I am a full-stack developer based in Dubai and I build web applications for companies in the UAE and abroad. I can meet in person in Dubai.
Should my web app use Angular or React?
Both are solid. I lean to Angular for large apps with many forms, roles and screens, and React for products that need to move fast with a lighter setup. I will recommend one after I understand your project.
Can you work with my existing backend or system?
Yes. Many of my projects sit on top of existing systems, from airline booking engines to health authority APIs. I can build the web app against your current APIs, or add the APIs it needs.
Can you take over or improve a web app that someone else built?
Yes. I start by reading the code and the deployment setup, then fix the riskiest problems first. I have migrated a monolith to microservices and brought update downtime close to zero on a live platform.
Do you handle hosting and deployment too?
Yes. I set up Docker, CI/CD and hosting on AWS or Azure, so releases are safe and repeatable after launch.
Do you also build the mobile app?
Yes. I build mobile apps with Flutter and React Native, and they can share the same backend as the web app.
